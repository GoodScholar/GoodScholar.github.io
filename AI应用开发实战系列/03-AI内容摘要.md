## 📊 为什么需要流式渲染？

| 方式 | 用户体验 | 等待时间 | 实现复杂度 |
|------|---------|---------|----------|
| 同步等待 | ❌ 白屏 3-10 秒后一次性显示 | 全部完成才返回 | ⭐ |
| 流式渲染 | ✅ 逐字显示，0.3 秒内开始 | 首字节 300ms | ⭐⭐⭐ |

> GPT-4o 生成 500 字摘要大约需要 5-8 秒。同步等待意味着用户盯着白屏 8 秒——这在移动端是不可接受的。

## 🌊 1. 理解 SSE（Server-Sent Events）

### SSE vs WebSocket vs Long Polling

| 特性 | SSE | WebSocket | Long Polling |
|------|-----|-----------|-------------|
| 通信方向 | 服务端 → 客户端（单向） | 双向 | 客户端轮询 |
| 协议 | HTTP | WS (独立协议) | HTTP |
| 自动重连 | ✅ 浏览器内置 | ❌ 需手动 | ❌ 需手动 |
| 适合 | AI 流式输出、通知推送 | 聊天室、实时协作 | 轮询更新 |
| 实现复杂度 | ⭐ | ⭐⭐⭐ | ⭐⭐ |

> **AI 流式输出是典型的「服务端持续推送」场景，SSE 是最合适的协议。**

### SSE 协议格式

```
HTTP/1.1 200 OK
Content-Type: text/event-stream
Cache-Control: no-cache

data: {"content": "这"}

data: {"content": "是"}

data: {"content": "一段"}

data: {"content": "摘要"}

data: [DONE]
```

## 🛠 2. 后端：流式摘要接口

### Node.js + Express 实现

```typescript
// routes/summary.ts
import express from 'express'
import OpenAI from 'openai'

const router = express.Router()
const openai = new OpenAI()

router.post('/api/summary', async (req, res) => {
  const { content, style = 'concise' } = req.body

  if (!content || content.length < 50) {
    return res.status(400).json({ error: '内容太短，无需摘要' })
  }

  // 设置 SSE 响应头
  res.setHeader('Content-Type', 'text/event-stream')
  res.setHeader('Cache-Control', 'no-cache')
  res.setHeader('Connection', 'keep-alive')

  try {
    const stream = await openai.chat.completions.create({
      model: 'gpt-4o-mini', // 摘要不需要最强模型
      messages: [
        {
          role: 'system',
          content: getSystemPrompt(style),
        },
        {
          role: 'user',
          content: `请为以下内容生成摘要：\n\n${content.slice(0, 8000)}`,
        },
      ],
      stream: true,
      max_tokens: 500,
      temperature: 0.3, // 低温度 = 更确定的输出
    })

    // 逐 chunk 推送
    for await (const chunk of stream) {
      const content = chunk.choices[0]?.delta?.content
      if (content) {
        res.write(`data: ${JSON.stringify({ content })}\n\n`)
      }
    }

    res.write('data: [DONE]\n\n')
    res.end()
  } catch (error) {
    res.write(`data: ${JSON.stringify({ error: '生成失败' })}\n\n`)
    res.end()
  }
})

function getSystemPrompt(style: string): string {
  const prompts: Record<string, string> = {
    concise: `你是一个内容摘要助手。请用 3-5 句话概括文章核心内容。
要求：
- 保留关键数据和结论
- 使用中文
- 不要添加你自己的观点
- 语言简洁直接`,

    bullet: `你是一个内容摘要助手。请用 3-5 个要点概括文章核心内容。
要求：
- 每个要点以 • 开头
- 每个要点不超过 20 个字
- 按重要性排序`,

    tweet: `你是一个社媒文案助手。请用一句话（不超过 100 字）总结文章核心观点。
要求有吸引力、有信息量，适合发推文/朋友圈。`,
  }
  return prompts[style] || prompts.concise
}

export default router
```

## 🎨 3. 前端：打字机效果

### React 流式渲染组件

```tsx
// components/AISummary.tsx
'use client'
import { useState, useRef } from 'react'

interface Props {
  content: string // 要摘要的原文
}

export function AISummary({ content }: Props) {
  const [summary, setSummary] = useState('')
  const [loading, setLoading] = useState(false)
  const [style, setStyle] = useState<'concise' | 'bullet' | 'tweet'>('concise')
  const abortRef = useRef<AbortController | null>(null)

  async function generateSummary() {
    // 取消之前的请求
    abortRef.current?.abort()
    abortRef.current = new AbortController()

    setLoading(true)
    setSummary('')

    try {
      const res = await fetch('/api/summary', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ content, style }),
        signal: abortRef.current.signal,
      })

      const reader = res.body?.getReader()
      const decoder = new TextDecoder()

      if (!reader) return

      while (true) {
        const { done, value } = await reader.read()
        if (done) break

        const text = decoder.decode(value)
        const lines = text.split('\n')

        for (const line of lines) {
          if (line.startsWith('data: ')) {
            const data = line.slice(6)
            if (data === '[DONE]') break

            try {
              const { content: chunk } = JSON.parse(data)
              if (chunk) {
                setSummary((prev) => prev + chunk) // 逐字追加
              }
            } catch {}
          }
        }
      }
    } catch (e) {
      if ((e as Error).name !== 'AbortError') {
        setSummary('摘要生成失败，请重试')
      }
    } finally {
      setLoading(false)
    }
  }

  return (
    <div className="ai-summary">
      <div className="summary-controls">
        <select value={style} onChange={(e) => setStyle(e.target.value as any)}>
          <option value="concise">简洁版</option>
          <option value="bullet">要点版</option>
          <option value="tweet">一句话版</option>
        </select>
        <button onClick={generateSummary} disabled={loading}>
          {loading ? '✨ AI 正在总结...' : '🤖 一键摘要'}
        </button>
      </div>

      {summary && (
        <div className="summary-content">
          {summary}
          {loading && <span className="cursor-blink">|</span>}
        </div>
      )}
    </div>
  )
}
```

## 📝 4. Prompt 工程要点

### 摘要 Prompt 的关键技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 指定角色 | 限制 AI 的行为边界 | `你是一个内容摘要助手` |
| 输出格式 | 控制输出结构 | `用 3-5 个要点概括` |
| 限制长度 | 避免过长输出 | `每个要点不超过 20 个字` |
| 负面约束 | 明确「不要做什么」 | `不要添加你自己的观点` |
| 温度控制 | API 参数 | `temperature: 0.3`（低 = 更确定） |

### 不同温度的效果

| 温度 | 输出特点 | 适合场景 |
|------|---------|---------|
| 0.0 | 最确定，几乎不变 | 数据提取、分类 |
| 0.3 | 稳定但有微小变化 | 摘要、翻译 |
| 0.7 | 有创意，表述多样 | 文案生成 |
| 1.0 | 非常随机 | 头脑风暴 |

## ⚡ 5. 缓存策略

### 为什么要缓存？

同一篇文章的摘要，不同用户请求的结果是一样的。缓存可以节省 90% 以上的 API 调用。

```typescript
// 内容指纹缓存
import { createHash } from 'crypto'
import { Redis } from 'ioredis'

const redis = new Redis(process.env.REDIS_URL)

function contentHash(content: string, style: string): string {
  return createHash('md5')
    .update(`${style}:${content.slice(0, 8000)}`)
    .digest('hex')
}

async function getCachedSummary(content: string, style: string) {
  const hash = contentHash(content, style)
  return redis.get(`summary:${hash}`)
}

async function cacheSummary(content: string, style: string, summary: string) {
  const hash = contentHash(content, style)
  await redis.setex(`summary:${hash}`, 86400 * 7, summary) // 缓存 7 天
}
```

### 缓存 + 流式的协调方案

```typescript
// 有缓存 → 一次性返回（快）
// 无缓存 → 流式生成（体验好）+ 存缓存
router.post('/api/summary', async (req, res) => {
  const { content, style } = req.body

  // 1. 检查缓存
  const cached = await getCachedSummary(content, style)
  if (cached) {
    return res.json({ summary: cached, cached: true })
  }

  // 2. 未命中 → 流式生成
  res.setHeader('Content-Type', 'text/event-stream')

  let fullSummary = ''
  // ...流式输出（同上）...
  // 每个 chunk 追加到 fullSummary

  // 3. 完成后写入缓存
  await cacheSummary(content, style, fullSummary)
})
```
