## 🧠 1. RAG 完整流程

### 什么是 RAG？

RAG（Retrieval-Augmented Generation）= 先检索，再生成。让 LLM 基于你的数据回答问题，而不是凭空编造。

```
用户问题: "退款政策是什么？"
    │
    ▼
Step 1: 把问题转为 Embedding
    │
    ▼
Step 2: 在向量数据库中搜索相似文档
    │ 找到: "退款政策.md", "常见问题.md"
    ▼
Step 3: 把问题 + 相关文档一起发给 LLM
    │ Prompt: "根据以下文档回答用户问题：[文档内容]"
    ▼
Step 4: LLM 基于文档内容生成回答
    │ "根据我们的退款政策，购买后 7 天内..."
    ▼
返回给用户（附带引用来源）
```

### 实现代码

```typescript
// services/rag.ts
import OpenAI from 'openai'
import { Pool } from 'pg'

const openai = new OpenAI()
const pool = new Pool({ connectionString: process.env.DATABASE_URL })

interface RAGResult {
  answer: string
  sources: { title: string; similarity: number }[]
}

async function ragQuery(question: string): Promise<RAGResult> {
  // Step 1：问题 → Embedding
  const questionEmbedding = await getEmbedding(question)

  // Step 2：向量搜索（取 Top 5 相关文档）
  const { rows: docs } = await pool.query(
    `SELECT id, title, content,
            1 - (embedding <=> $1::vector) AS similarity
     FROM documents
     WHERE 1 - (embedding <=> $1::vector) > 0.7
     ORDER BY embedding <=> $1::vector
     LIMIT 5`,
    [`[${questionEmbedding.join(',')}]`]
  )

  if (docs.length === 0) {
    return { answer: '抱歉，我没有找到相关信息。', sources: [] }
  }

  // Step 3：构建 Prompt
  const context = docs
    .map((d, i) => `[文档${i + 1}: ${d.title}]\n${d.content}`)
    .join('\n\n---\n\n')

  // Step 4：LLM 生成回答
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      {
        role: 'system',
        content: `你是一个客服助手。请仅根据下方提供的文档回答用户问题。
如果文档中没有相关信息，说"抱歉，我无法回答这个问题"。
回答时引用文档编号，如 [文档1]。

---参考文档---
${context}`,
      },
      { role: 'user', content: question },
    ],
    temperature: 0.2,
    max_tokens: 800,
  })

  return {
    answer: response.choices[0].message.content!,
    sources: docs.map((d) => ({
      title: d.title,
      similarity: Math.round(d.similarity * 100) / 100,
    })),
  }
}
```

### RAG 质量优化

| 优化方向 | 方法 | 效果 |
|---------|------|------|
| **分块策略** | 按段落/标题切分，每块 200-500 字 | 提高检索精度 |
| **重叠分块** | 块与块之间重叠 10-20% | 避免上下文断裂 |
| **混合检索** | 向量 + 关键词双路召回 | 提高召回率 |
| **重排序** | 用 Cross-Encoder 对结果排序 | 提高相关性 |
| **Prompt 约束** | 明确要求引用来源 | 减少幻觉 |

## 🔧 2. Function Calling

### 什么是 Function Calling？

让 LLM「调用函数」——你告诉 LLM 有哪些工具可用，LLM 根据用户意图决定调用哪个。

```
用户: "帮我查一下北京明天的天气"
    │
    ▼
LLM 判断: 需要调用 get_weather 函数
    │ 参数: { city: "北京", date: "明天" }
    ▼
你的代码: 调用天气 API → 获取结果
    │ 结果: { temp: 28, weather: "晴" }
    ▼
LLM: 基于结果生成自然语言回答
    │ "北京明天天气晴，最高温度28°C。"
    ▼
返回给用户
```

### 完整实现

```typescript
// services/assistant.ts
import OpenAI from 'openai'

const openai = new OpenAI()

// 1. 定义工具
const tools: OpenAI.ChatCompletionTool[] = [
  {
    type: 'function',
    function: {
      name: 'get_weather',
      description: '获取指定城市的天气信息',
      parameters: {
        type: 'object',
        properties: {
          city: { type: 'string', description: '城市名称' },
          date: { type: 'string', description: '日期（今天/明天/后天）' },
        },
        required: ['city'],
      },
    },
  },
  {
    type: 'function',
    function: {
      name: 'create_reminder',
      description: '创建一个提醒事项',
      parameters: {
        type: 'object',
        properties: {
          title: { type: 'string', description: '提醒标题' },
          time: { type: 'string', description: '提醒时间，ISO 格式' },
        },
        required: ['title', 'time'],
      },
    },
  },
  {
    type: 'function',
    function: {
      name: 'search_articles',
      description: '搜索相关文章或文档',
      parameters: {
        type: 'object',
        properties: {
          query: { type: 'string', description: '搜索关键词' },
        },
        required: ['query'],
      },
    },
  },
]

// 2. 工具实现
const toolHandlers: Record<string, (args: any) => Promise<any>> = {
  get_weather: async ({ city, date }) => {
    // 调用真实天气 API
    const res = await fetch(
      `https://api.weather.com/v1/${city}?date=${date || 'today'}`
    )
    return res.json()
  },
  create_reminder: async ({ title, time }) => {
    // 写入数据库
    await db.reminders.create({ title, time: new Date(time) })
    return { success: true, message: `提醒"${title}"已创建` }
  },
  search_articles: async ({ query }) => {
    // 复用第 2 篇的语义搜索
    return semanticSearch(query, 3)
  },
}

// 3. 对话循环
async function chat(messages: OpenAI.ChatCompletionMessage[]) {
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      { role: 'system', content: '你是一个全能助手，可以查天气、创建提醒、搜索文章。' },
      ...messages,
    ],
    tools,
    tool_choice: 'auto', // LLM 自行决定是否调用工具
  })

  const assistantMessage = response.choices[0].message

  // 检查是否需要调用工具
  if (assistantMessage.tool_calls) {
    // 执行所有工具调用
    const toolResults = await Promise.all(
      assistantMessage.tool_calls.map(async (call) => {
        const handler = toolHandlers[call.function.name]
        const args = JSON.parse(call.function.arguments)
        const result = await handler(args)

        return {
          role: 'tool' as const,
          tool_call_id: call.id,
          content: JSON.stringify(result),
        }
      })
    )

    // 把工具结果回传给 LLM，让它生成最终回答
    return chat([...messages, assistantMessage, ...toolResults])
  }

  // 不需要工具，直接返回回答
  return assistantMessage.content
}
```

## 💬 3. 多轮对话与上下文管理

### 上下文窗口管理

```typescript
// 滑动窗口：只保留最近 N 轮对话
function trimMessages(
  messages: Message[],
  maxTokens: number = 4000
): Message[] {
  let totalTokens = 0
  const result: Message[] = []

  // 从最新消息往前保留
  for (let i = messages.length - 1; i >= 0; i--) {
    const msgTokens = estimateTokens(messages[i].content)
    if (totalTokens + msgTokens > maxTokens) break
    result.unshift(messages[i])
    totalTokens += msgTokens
  }

  return result
}

function estimateTokens(text: string): number {
  // 粗略估算：中文约 1.5 字/Token，英文约 4 字符/Token
  return Math.ceil(text.length / 1.5)
}
```

### 对话摘要压缩

```typescript
// 当对话超过阈值时，用 LLM 压缩历史
async function compressHistory(messages: Message[]): Promise<string> {
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      {
        role: 'system',
        content: '请用 3-5 句话总结以下对话的关键信息，保留重要的数据和结论。',
      },
      {
        role: 'user',
        content: messages.map((m) => `${m.role}: ${m.content}`).join('\n'),
      },
    ],
    max_tokens: 300,
  })
  return response.choices[0].message.content!
}
```

## 🛡️ 4. 幻觉抑制策略

| 策略 | 做法 | 有效性 |
|------|------|--------|
| **RAG 约束** | 只允许基于提供的文档回答 | ⭐⭐⭐⭐⭐ |
| **Prompt 约束** | 「如果不确定，说不知道」 | ⭐⭐⭐⭐ |
| **低温度** | `temperature: 0.1-0.3` | ⭐⭐⭐ |
| **结构化输出** | 要求 JSON 格式回答 | ⭐⭐⭐ |
