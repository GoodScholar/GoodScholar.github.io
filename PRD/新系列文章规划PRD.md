# 新系列文章规划 PRD

## 概述

基于对已有 15 个系列、90+ 篇文章的全面盘点，识别出内容矩阵的三大结构性缺口：**进阶深度不足**、**AI 应用落地空白**、**独立开发方向缺失**。本规划以填补这些空白为目标，提出 4 个新系列、共 36 篇文章的创作计划。

## 现状分析

```
已覆盖:
  ✅ Flutter / RN / Taro / Node.js 入门教程
  ✅ AI 编程工具（Skills / GStack / Vibe-Coding）
  ✅ 跨端技术选型与架构
  ✅ 插件工具评测

未覆盖:
  ❌ Flutter 进阶（入门读者的下一站）
  ❌ AI 应用开发（不是用 AI 写代码，是用 AI 做产品）
  ❌ 独立开发者完整路径（从想法到赚钱）
  ❌ iOS 原生开发（SwiftUI）
```

## 执行优先级

```
Tier 1（立即启动，流量最确定）
  ├── 📘 Flutter 进阶实战系列（10 篇）
  └── 🤖 AI 应用开发实战系列（8 篇）

Tier 2（穿插进行，新风口）
  └── 🚀 独立开发者实战系列（8 篇）

Tier 3（后续规划）
  └── 🍎 SwiftUI 从零到一系列（10 篇）
```

## 系列一：Flutter 进阶实战系列（10 篇）

### 定位

「Flutter 从零到一」的天然续集。读者学完基础之后的进阶之路，覆盖自定义组件、复杂动画、性能调优、架构设计等高级话题。

### 目标读者

- 学完 Flutter 入门系列，想进一步提升的开发者
- 有 1-2 年 Flutter 经验，遇到性能/架构瓶颈的工程师
- 准备面试高级 Flutter 岗位的求职者

### 系列目录

| # | 标题 | 核心内容 | 选题类型 |
|---|------|---------|---------|
| 01 | 自定义 Widget 深入 — 从 Container 到 RenderObject | CustomPainter、RenderBox、布局协议、绘制管线 | 🔥 痛点解决 |
| 02 | 复杂动画编排 — Hero + 物理引擎 + Rive 实战 | 隐式/显式动画、AnimationController 组合、Rive 集成 | 🛠️ 实战演练 |
| 03 | 高性能列表 — 瀑布流 + 无限滚动 + 智能预加载 | Sliver 体系、CustomScrollView、缓存策略、帧率优化 | 🛠️ 实战演练 |
| 04 | 原生混编实战 — Platform Channel + Pigeon + FFI | MethodChannel、EventChannel、Pigeon 代码生成、dart:ffi | 🔥 痛点解决 |
| 05 | 状态管理进阶 — Riverpod 源码剖析与架构模式 | Provider 树、AsyncNotifier、状态持久化、测试策略 | 💡 认知升级 |
| 06 | App 架构设计 — Clean Architecture 落地指南 | Repository 模式、依赖注入、领域层设计、分层解耦 | 🛠️ 实战演练 |
| 07 | 插件开发从零到发布 — 从使用者到创造者 | Federated Plugin、Platform Interface、发布到 pub.dev | 🛠️ 实战演练 |
| 08 | 性能调优全链路 — 启动 / 渲染 / 内存 / 包体积 | DevTools 实战、Timeline、Memory、Shader 预热、Tree Shaking | ⚔️ 横评对比 |
| 09 | 自动化测试体系 — 单元 / Widget / 集成 / E2E | Mockito、Golden Test、Integration Test、Patrol | 📋 清单速查 |
| 10 | 从开发到上架 — CI/CD + Fastlane + 审核全攻略 | GitHub Actions、Fastlane、 flavors 多环境、审核避坑 | 🛠️ 实战演练 |

### 内容要求

- 每篇假设读者已掌握「Flutter 从零到一」的全部内容
- 每篇必须有**完整可运行的示例项目**（不是代码片段）
- 每篇至少 3 张对比表格 + 1 个架构图/流程图
- 从第 01 篇到第 10 篇形成递进关系，可独立阅读也可串联学习

### 技术覆盖路径

```
自定义组件 → 动画 → 列表 → 原生混编 → 状态管理 → 架构 → 插件 → 性能 → 测试 → 发布
```

## 系列二：AI 应用开发实战系列（8 篇）

### 定位

不是「用 AI 写代码」，而是「用 AI 做产品功能」。教前端/App 开发者在自己的产品中落地 AI 能力，每篇都是完整的端到端实战。

### 目标读者

- 想在自己的 App/网站中接入 AI 能力的开发者
- 有前端基础，对 LLM/Embedding/RAG 好奇的工程师
- 产品经理/技术负责人，需要评估 AI 功能可行性

### 系列目录

| # | 标题 | 核心内容 | 选题类型 |
|---|------|---------|---------|
| 01 | 给你的 App 接上 AI — 架构设计与模型选型 | 云端 vs 端侧、模型评测、成本估算、技术栈选择 | 📋 清单速查 |
| 02 | 语义搜索实战 — Embedding + 向量数据库 | text-embedding-3、pgvector、Milvus、相似度算法 | 🛠️ 实战演练 |
| 03 | AI 内容摘要 — LLM Streaming + 流式渲染 | SSE、打字机效果、Prompt 工程、缓存策略 | 🛠️ 实战演练 |
| 04 | 对话式 AI 助手 — RAG + Function Calling | 知识库构建、上下文管理、幻觉抑制、多轮记忆 | 🛠️ 实战演练 |
| 05 | AI 图像能力 — 智能裁剪 / 描述生成 / 风格迁移 | GPT-4o Vision、DALL·E 3、图像分析、前端集成 | 🛠️ 实战演练 |
| 06 | 端侧 AI 推理 — 在手机上跑模型 | ONNX Runtime、CoreML、TFLite、Flutter 集成 | 🔥 痛点解决 |
| 07 | AI Agent 开发 — 让 AI 自己完成多步任务 | Agent Loop、Tool Use、Planning、异步执行 | 💡 认知升级 |
| 08 | AI 功能的生产化 — 成本管控 / 监控 / 灰度发布 | Token 预算、A/B 测试、降级策略、可观测性 | 📋 清单速查 |

### 内容要求

- 每篇包含**前端 + 后端**完整代码（不只是 API 调用示例）
- 每篇必须有**成本分析表格**（按 DAU 分级的月费估算）
- 每篇必须说清楚「什么场景适合 / 不适合」
- 代码示例优先用 TypeScript + React，辅以 Flutter/Dart

### 技术覆盖路径

```
架构选型 → 搜索 → 摘要 → 对话 → 图像 → 端侧 → Agent → 生产化
```
