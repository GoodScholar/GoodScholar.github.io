# 文章 HTML 预览设计

## 目标

为微信公众号和掘金文章提供本地 HTML 预览页，方便在正式发布前检查版式，并复制适合目标平台的正文。完整文章生成后先询问用户；用户确认后生成预览。文章进入修改模式并输出完整正文后，再次询问，确认后覆盖同名 HTML 文件。

## 入口与兼容

新增通用工具 `tools/generate_article_preview.py`，命令形式：

```bash
python tools/generate_article_preview.py <文章.md> --platform wechat|juejin [--output <预览.html>]
```

现有 `tools/publish_to_wechat.py <文章.md> --html-only` 保持可用，不改变公众号发布和凭证逻辑。新工具不读取平台凭证、不上传文件、不执行发布。

## 平台预览契约

### 微信公众号

- 使用现有公众号 Markdown 转 HTML 能力和公众号样式。
- 文章区模拟手机阅读宽度，操作区提供“复制排版正文”和“复制 Markdown”。
- 复制排版正文优先写入 `text/html`，兼容降级到选区复制；复制 Markdown 始终保留原始 Markdown。
- 操作提示只说明复制到公众号编辑器，不在预览页执行发布。

### 掘金

- 使用标准 Markdown 语义渲染，保留标题、列表、引用、链接、图片、围栏代码块和表格。
- 文章区采用适合桌面和移动端的技术文章阅读宽度，代码块可横向滚动。
- 操作区提供“复制 Markdown”和“复制正文文本”；不显示公众号转发文案、微信编辑器提示或草稿箱发布步骤。
- HTML 预览不改变原始 Markdown，不新增自动发布能力。

## 页面交互

- 页面显示标题、目标平台、文章预览和复制操作。
- 复制成功显示短暂状态反馈；复制失败显示可执行的降级提示。
- 桌面端使用文章区 + 操作区布局，窄屏自动改为上下布局。
- 生成文件默认与 Markdown 同名、扩展名改为 `.html`；`--output` 可覆盖默认路径。

## Skill 流程调整

- 完整文章输出结束后，询问是否生成 HTML 预览页；未确认不自动生成。
- 修改模式输出完整文章后使用同样询问；确认后覆盖对应 HTML 文件。
- 用户明确要求“预览”“生成 HTML”“方便复制”时，视为已确认，可直接生成。
- 生成成功后返回 HTML 文件路径和目标平台；失败时保留文章交付，并说明失败原因。

## 验证标准

- 微信和掘金 fixture 均能生成 HTML，默认路径和 `--output` 路径正确。
- 微信页面包含富文本复制和 Markdown 复制入口；掘金页面包含 Markdown 复制入口且不包含微信发布提示。
- 生成工具不读取 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`，不调用网络发布接口。
- 现有 `publish_to_wechat.py --html-only` 行为保持通过。
- HTML 中的文章标题、代码、链接、图片和特殊字符经过安全转义，不破坏页面结构。
