# 🎯 Flutter 进阶实战（四）：原生混编实战 — Platform Channel + Pigeon + FFI

> **系列导读**：这是「Flutter 进阶实战」系列的第 4 篇。Flutter 能覆盖 90% 的 UI 需求，
> 但剩下的 10%——蓝牙、生物识别、特定 SDK——必须调用原生。本篇教你打通 Flutter 和原生的桥梁。

**本文目标**：掌握 MethodChannel、EventChannel、Pigeon 代码生成、dart:ffi 四种混编方式，能根据场景选择最合适的方案。

---

## 📊 什么时候需要混编？

| 场景 | Flutter 能做？ | 需要原生？ |
|------|-------------|----------|
| 常规 UI + 网络请求 | ✅ | ❌ |
| 系统相机/相册 | ⚠️ 插件覆盖 | 深度定制需要 |
| 蓝牙 / NFC | ❌ | ✅ |
| 生物识别 | ⚠️ local_auth 插件 | 自定义 UI 需要 |
| 集成第三方 SDK | ❌ | ✅ |
| 高性能计算（图像/音视频） | ❌ | ✅ (C/C++) |
| 系统级 API（健康/通讯录） | ❌ | ✅ |

### 混编方案选型

| 方案 | 通信方向 | 类型安全 | 适用场景 |
|------|---------|---------|---------|
| **MethodChannel** | 双向（请求-响应） | ❌ 手动序列化 | 快速原型、简单调用 |
| **EventChannel** | 原生 → Flutter（持续流） | ❌ 手动序列化 | 传感器数据、蓝牙推送 |
| **Pigeon** | 双向 | ✅ 代码生成 | 正式项目（推荐） |
| **FFI** | Flutter → C/C++ | ✅ 类型映射 | 高性能计算、加密库 |

## 📡 1. MethodChannel：最基础的桥梁

### 工作原理

```
Flutter (Dart)                   Native (Swift/Kotlin)
┌──────────────┐                ┌──────────────┐
│              │    invoke()    │              │
│ MethodChannel│───────────────→│ MethodChannel│
│ ('com.app/   │                │ (handler)    │
│   battery')  │◄───────────────│              │
│              │    result      │              │
└──────────────┘                └──────────────┘
```

### Flutter 端

```dart
class BatteryService {
  static const _channel = MethodChannel('com.example/battery');

  // Flutter → Native：获取电量
  static Future<int> getBatteryLevel() async {
    try {
      final int level = await _channel.invokeMethod('getBatteryLevel');
      return level;
    } on PlatformException catch (e) {
      throw Exception('获取电量失败: ${e.message}');
    }
  }

  // Flutter → Native：带参数
  static Future<bool> setBrightness(double value) async {
    return await _channel.invokeMethod('setBrightness', {'value': value});
  }
}
```

### Android 端 (Kotlin)

```kotlin
// android/app/src/main/kotlin/.../MainActivity.kt
class MainActivity : FlutterActivity() {
    private val CHANNEL = "com.example/battery"

    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)

        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, CHANNEL)
            .setMethodCallHandler { call, result ->
                when (call.method) {
                    "getBatteryLevel" -> {
                        val batteryLevel = getBatteryLevel()
                        if (batteryLevel != -1) {
                            result.success(batteryLevel)
                        } else {
                            result.error("UNAVAILABLE", "Battery level not available", null)
                        }
                    }
                    "setBrightness" -> {
                        val value = call.argument<Double>("value") ?: 0.5
                        // 设置亮度...
                        result.success(true)
                    }
                    else -> result.notImplemented()
                }
            }
    }

    private fun getBatteryLevel(): Int {
        val batteryManager = getSystemService(BATTERY_SERVICE) as BatteryManager
        return batteryManager.getIntProperty(BatteryManager.BATTERY_PROPERTY_CAPACITY)
    }
}
```

### iOS 端 (Swift)

```swift
// ios/Runner/AppDelegate.swift
@main
@objc class AppDelegate: FlutterAppDelegate {
    override func application(
        _ application: UIApplication,
        didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
    ) -> Bool {
        let controller = window?.rootViewController as! FlutterViewController
        let channel = FlutterMethodChannel(
            name: "com.example/battery",
            binaryMessenger: controller.binaryMessenger
        )

        channel.setMethodCallHandler { (call, result) in
            switch call.method {
            case "getBatteryLevel":
                let device = UIDevice.current
                device.isBatteryMonitoringEnabled = true
                let level = Int(device.batteryLevel * 100)
                result(level)
            case "setBrightness":
                if let args = call.arguments as? [String: Any],
                   let value = args["value"] as? Double {
                    UIScreen.main.brightness = CGFloat(value)
                    result(true)
                } else {
                    result(FlutterError(code: "INVALID_ARGS", message: nil, details: nil))
                }
            default:
                result(FlutterMethodNotImplemented)
            }
        }

        return super.application(application, didFinishLaunchingWithOptions: launchOptions)
    }
}
```

## 🌊 2. EventChannel：持续数据流

### 适用场景

传感器数据、蓝牙设备通知、GPS 位置更新——这些是持续推送的数据流，用 `EventChannel`。

### Flutter 端

```dart
class SensorService {
  static const _channel = EventChannel('com.example/accelerometer');

  // 获取加速度计数据流
  static Stream<AccelerometerData> get accelerometerStream {
    return _channel.receiveBroadcastStream().map((event) {
      final map = Map<String, double>.from(event);
      return AccelerometerData(
        x: map['x']!,
        y: map['y']!,
        z: map['z']!,
      );
    });
  }
}

// 在 Widget 中使用
StreamBuilder<AccelerometerData>(
  stream: SensorService.accelerometerStream,
  builder: (context, snapshot) {
    if (!snapshot.hasData) return Text('等待数据...');
    final data = snapshot.data!;
    return Text('X: ${data.x.toStringAsFixed(2)}, '
                'Y: ${data.y.toStringAsFixed(2)}, '
                'Z: ${data.z.toStringAsFixed(2)}');
  },
)
```

### Android 端 (Kotlin)

```kotlin
EventChannel(flutterEngine.dartExecutor.binaryMessenger, "com.example/accelerometer")
    .setStreamHandler(object : EventChannel.StreamHandler {
        private var sensorManager: SensorManager? = null
        private var listener: SensorEventListener? = null

        override fun onListen(arguments: Any?, events: EventChannel.EventSink) {
            sensorManager = getSystemService(SENSOR_SERVICE) as SensorManager
            val accelerometer = sensorManager!!.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)

            listener = object : SensorEventListener {
                override fun onSensorChanged(event: SensorEvent) {
                    events.success(mapOf(
                        "x" to event.values[0].toDouble(),
                        "y" to event.values[1].toDouble(),
                        "z" to event.values[2].toDouble(),
                    ))
                }
                override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
            }

            sensorManager!!.registerListener(listener, accelerometer,
                SensorManager.SENSOR_DELAY_UI)
        }

        override fun onCancel(arguments: Any?) {
            sensorManager?.unregisterListener(listener)
        }
    })
```

## 🕊️ 3. Pigeon：类型安全的代码生成

### 为什么用 Pigeon？

| 对比 | MethodChannel | Pigeon |
|------|-------------|--------|
| 类型安全 | ❌ 手动 as 转换 | ✅ 生成强类型接口 |
| 序列化 | ❌ 手动 Map 解析 | ✅ 自动 |
| API 文档 | ❌ 靠注释 | ✅ 代码即文档 |
| 双端对齐 | ❌ 容易不一致 | ✅ 一处定义，双端生成 |
| 维护成本 | 高 | 低 |

### 使用步骤

```yaml
# pubspec.yaml
dev_dependencies:
  pigeon: ^22.0.0
```

**1. 定义接口（Dart 文件）**

```dart
// pigeons/battery_api.dart
import 'package:pigeon/pigeon.dart';

class BatteryInfo {
  int? level;
  String? status; // charging / discharging / full
  double? temperature;
}

@HostApi() // Flutter 调用 → Native 实现
abstract class BatteryHostApi {
  BatteryInfo getBatteryInfo();
  void setBrightness(double value);
}

@FlutterApi() // Native 调用 → Flutter 实现
abstract class BatteryFlutterApi {
  void onBatteryLow(int level);
}
```

**2. 运行代码生成**

```bash
dart run pigeon \
  --input pigeons/battery_api.dart \
  --dart_out lib/generated/battery_api.g.dart \
  --kotlin_out android/app/src/main/kotlin/.../BatteryApi.g.kt \
  --swift_out ios/Runner/BatteryApi.g.swift
```

**3. Flutter 端直接调用（有类型提示）**

```dart
final api = BatteryHostApi();
final info = await api.getBatteryInfo();
print('电量: ${info.level}%, 状态: ${info.status}');
```

## 🔧 4. dart:ffi — 调用 C/C++ 代码

### 适用场景

高性能计算、加密算法、图像处理、复用已有的 C/C++ 库。

### 简单示例：调用 C 函数

```c
// native/src/math_utils.c
#include <math.h>

// 导出函数：计算两点之间的距离
double distance(double x1, double y1, double x2, double y2) {
    return sqrt(pow(x2 - x1, 2) + pow(y2 - y1, 2));
}

// 导出函数：快速排序
void quick_sort(int* arr, int len) {
    // ... 排序实现
}
```

```dart
// lib/native/math_bridge.dart
import 'dart:ffi';
import 'dart:io';

// 定义 C 函数签名
typedef DistanceNative = Double Function(
    Double x1, Double y1, Double x2, Double y2);
typedef DistanceDart = double Function(
    double x1, double y1, double x2, double y2);

class MathBridge {
  late final DynamicLibrary _lib;
  late final DistanceDart distance;

  MathBridge() {
    // 加载动态库
    _lib = Platform.isAndroid
        ? DynamicLibrary.open('libmath_utils.so')
        : DynamicLibrary.process(); // iOS 静态链接

    // 查找并绑定函数
    distance = _lib
        .lookupFunction<DistanceNative, DistanceDart>('distance');
  }
}

// 使用
final math = MathBridge();
final d = math.distance(0, 0, 3, 4); // 5.0
```

### FFI vs MethodChannel 性能对比

| 场景 | MethodChannel | FFI |
|------|-------------|-----|
| 单次调用延迟 | ~0.5ms | ~0.01ms |
| 大数据传递 | 需要序列化（慢） | 直接指针（快） |
| 调用频率 | 不适合高频 | 适合每帧调用 |
| 开发复杂度 | 低 | 高（需要写 C） |
