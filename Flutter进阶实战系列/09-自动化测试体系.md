## 📊 测试金字塔

```
        ╱╲
       ╱  ╲       E2E 测试        — 少量，验证关键用户流程
      ╱────╲      Patrol / Appium
     ╱      ╲
    ╱────────╲    集成测试          — 适量，验证模块协作
   ╱          ╲   integration_test
  ╱────────────╲  Widget 测试      — 大量，验证 UI 行为
 ╱              ╲ flutter_test
╱────────────────╲ 单元测试        — 最多，验证逻辑正确
                   test + mockito
```

### 各层对比

| 层次 | 速度 | 可靠性 | 覆盖范围 | 推荐占比 |
|------|------|--------|---------|---------|
| 单元测试 | ⚡ 毫秒 | ⭐⭐⭐⭐⭐ | 单个函数/类 | 60% |
| Widget 测试 | ⚡ 百毫秒 | ⭐⭐⭐⭐ | 单个组件 | 25% |
| 集成测试 | 🐢 数秒 | ⭐⭐⭐ | 多组件协作 | 10% |
| E2E 测试 | 🐌 数十秒 | ⭐⭐ | 完整用户流程 | 5% |

## 🧪 1. 单元测试

### 基础测试

```dart
// test/models/article_test.dart
import 'package:test/test.dart';

void main() {
  group('Article', () {
    test('fromJson parses correctly', () {
      final json = {
        'id': '123',
        'title': 'Test Article',
        'content': 'Hello World',
        'author': 'NIHoa',
        'created_at': '2025-06-09',
      };

      final article = Article.fromJson(json);

      expect(article.id, '123');
      expect(article.title, 'Test Article');
      expect(article.author, 'NIHoa');
    });

    test('toJson produces correct map', () {
      final article = Article(
        id: '123',
        title: 'Test',
        content: 'Content',
        author: 'Author',
        createdAt: DateTime(2025, 6, 9),
      );

      final json = article.toJson();

      expect(json['id'], '123');
      expect(json['title'], 'Test');
    });
  });
}
```

### Mockito 模拟依赖

```dart
// test/repositories/article_repository_test.dart
import 'package:mockito/annotations.dart';
import 'package:mockito/mockito.dart';

@GenerateMocks([ArticleRemoteSource, ArticleLocalSource])
void main() {
  late MockArticleRemoteSource mockRemote;
  late MockArticleLocalSource mockLocal;
  late ArticleRepositoryImpl repository;

  setUp(() {
    mockRemote = MockArticleRemoteSource();
    mockLocal = MockArticleLocalSource();
    repository = ArticleRepositoryImpl(
      remoteSource: mockRemote,
      localSource: mockLocal,
    );
  });

  group('getArticles', () {
    test('returns articles from remote source', () async {
      // Arrange
      final testArticles = [
        ArticleDto(id: '1', title: 'Test', content: '', author: '',
            createdAt: '2025-06-09'),
      ];
      when(mockRemote.getArticles(page: 1, limit: 20))
          .thenAnswer((_) async => testArticles);
      when(mockLocal.cacheArticles(any)).thenAnswer((_) async {});

      // Act
      final result = await repository.getArticles();

      // Assert
      expect(result, hasLength(1));
      expect(result.first.id, '1');
      verify(mockLocal.cacheArticles(testArticles)).called(1);
    });

    test('returns cached articles on network failure', () async {
      when(mockRemote.getArticles(page: 1, limit: 20))
          .thenThrow(Exception('Network error'));
      when(mockLocal.getCachedArticles())
          .thenAnswer((_) async => [testArticleDto]);

      final result = await repository.getArticles();

      expect(result, hasLength(1));
      verify(mockLocal.getCachedArticles()).called(1);
    });
  });
}
```

### 异步测试 + FakeAsync

```dart
test('timer fires after 5 seconds', () {
  fakeAsync((fake) {
    var fired = false;
    Timer(Duration(seconds: 5), () => fired = true);

    fake.elapse(Duration(seconds: 4));
    expect(fired, false);

    fake.elapse(Duration(seconds: 1));
    expect(fired, true);
  });
});
```

## 🎨 2. Widget 测试

### 基础 Widget 测试

```dart
// test/widgets/article_card_test.dart
void main() {
  testWidgets('ArticleCard displays title and author', (tester) async {
    final article = Article(
      id: '1',
      title: '测试文章',
      content: '内容',
      author: 'NIHoa',
      createdAt: DateTime.now(),
    );

    await tester.pumpWidget(
      MaterialApp(
        home: Scaffold(
          body: ArticleCard(
            article: article,
            onTap: () {},
          ),
        ),
      ),
    );

    // 验证标题显示
    expect(find.text('测试文章'), findsOneWidget);
    // 验证作者显示
    expect(find.text('NIHoa'), findsOneWidget);
  });

  testWidgets('ArticleCard calls onTap when pressed', (tester) async {
    var tapped = false;

    await tester.pumpWidget(
      MaterialApp(
        home: Scaffold(
          body: ArticleCard(
            article: testArticle,
            onTap: () => tapped = true,
          ),
        ),
      ),
    );

    await tester.tap(find.byType(ArticleCard));
    expect(tapped, true);
  });
}
```

### Golden Test（视觉回归测试）

```dart
testWidgets('ArticleCard matches golden file', (tester) async {
  await tester.pumpWidget(
    MaterialApp(
      home: Scaffold(
        body: Center(
          child: SizedBox(
            width: 400,
            child: ArticleCard(article: testArticle, onTap: () {}),
          ),
        ),
      ),
    ),
  );

  // 生成基准截图：flutter test --update-goldens
  // 后续运行会自动对比
  await expectLater(
    find.byType(ArticleCard),
    matchesGoldenFile('goldens/article_card.png'),
  );
});
```

### 常用 Finder 和 Matcher

| Finder | 用途 |
|--------|------|
| `find.text('xxx')` | 按文本查找 |
| `find.byType(MyWidget)` | 按类型查找 |
| `find.byKey(Key('xxx'))` | 按 Key 查找 |
| `find.byIcon(Icons.add)` | 按图标查找 |
| `find.descendant(of: x, matching: y)` | 在子树中查找 |

| Matcher | 用途 |
|---------|------|
| `findsOneWidget` | 恰好找到 1 个 |
| `findsNothing` | 没找到 |
| `findsNWidgets(n)` | 找到 n 个 |
| `findsAtLeastNWidgets(n)` | 至少 n 个 |

## 🔗 3. 集成测试

```dart
// integration_test/app_test.dart
import 'package:integration_test/integration_test.dart';

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  testWidgets('login and view article flow', (tester) async {
    await tester.pumpWidget(const MyApp());
    await tester.pumpAndSettle();

    // 1. 登录页
    await tester.enterText(
      find.byKey(Key('email_field')), 'test@example.com',
    );
    await tester.enterText(
      find.byKey(Key('password_field')), 'password123',
    );
    await tester.tap(find.byKey(Key('login_button')));
    await tester.pumpAndSettle();

    // 2. 首页 - 验证文章列表
    expect(find.byType(ArticleCard), findsWidgets);

    // 3. 点击第一篇文章
    await tester.tap(find.byType(ArticleCard).first);
    await tester.pumpAndSettle();

    // 4. 详情页 - 验证显示
    expect(find.byType(DetailPage), findsOneWidget);

    // 5. 收藏文章
    await tester.tap(find.byIcon(Icons.favorite_border));
    await tester.pumpAndSettle();
    expect(find.byIcon(Icons.favorite), findsOneWidget);
  });
}
```

## 🤖 4. CI 集成

### GitHub Actions

```yaml
# .github/workflows/test.yml
name: Flutter Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.x'

      - run: flutter pub get

      # 代码分析
      - run: flutter analyze

      # 单元测试 + Widget 测试
      - run: flutter test --coverage

      # 覆盖率报告
      - uses: codecov/codecov-action@v4
        with:
          file: coverage/lcov.info
```

### 覆盖率目标

| 模块 | 目标覆盖率 | 优先级 |

| Data 层（Repository） | > 80% | ⭐⭐⭐⭐ |
