## 📊 动画选择决策树

面对一个动画需求，先判断用什么方案：

```
你需要做什么动画？
    │
    ├── 简单的属性变化（大小/颜色/位置）
    │   └── 隐式动画 → AnimatedContainer / AnimatedOpacity
    │
    ├── 需要精确控制（时间/曲线/多段）
    │   └── 显式动画 → AnimationController + Tween
    │
    ├── 多个动画按顺序/交错执行
    │   └── 交错动画 → Staggered Animation
    │
    ├── 页面间共享元素过渡
    │   └── Hero 动画 → Hero + flightShuttleBuilder
    │
    ├── 需要弹性/摩擦/重力效果
    │   └── 物理动画 → SpringSimulation / AnimateWith
    │
    └── 复杂的交互式动画/角色动画
        └── Rive → .riv 文件 + StateMachineController
```

### 方案对比

| 方案 | 复杂度 | 可控性 | 性能 | 适合场景 |
|------|--------|--------|------|---------|
| 隐式动画 | ⭐ | 低 | 高 | 按钮状态/简单过渡 |
| 显式动画 | ⭐⭐ | 高 | 高 | 自定义缓动/循环/精确控制 |
| 交错动画 | ⭐⭐⭐ | 高 | 高 | 列表入场/多元素协调 |
| Hero | ⭐⭐ | 中 | 高 | 页面间共享元素 |
| 物理引擎 | ⭐⭐⭐ | 高 | 高 | 弹性/摩擦/真实感 |
| Rive | ⭐⭐ | 极高 | 极高 | Logo/角色/复杂交互动画 |

## 🎭 1. 交错动画编排（Staggered Animation）

### 什么是交错动画？

多个动画**共用一个 AnimationController**，但各自在不同的时间区间内执行：

```
Controller: 0.0 ────────────────────── 1.0
动画A:     |████████|                       (0.0 ~ 0.3)
动画B:          |████████|                  (0.2 ~ 0.5)
动画C:               |████████|             (0.4 ~ 0.7)
动画D:                    |████████████|    (0.5 ~ 1.0)
```

### 实战：卡片入场动画

```dart
class StaggeredCardList extends StatefulWidget {
  const StaggeredCardList({super.key});

  @override
  State<StaggeredCardList> createState() => _StaggeredCardListState();
}

class _StaggeredCardListState extends State<StaggeredCardList>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  final int itemCount = 5;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 1500),
    )..forward(); // 页面打开时自动播放
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  // 为每个 item 计算独立的动画区间
  Animation<double> _buildSlideAnimation(int index) {
    final start = index * 0.1;         // 每个 item 错开 10%
    final end = start + 0.4;           // 每个动画持续 40%
    return Tween<double>(begin: 100, end: 0).animate(
      CurvedAnimation(
        parent: _controller,
        curve: Interval(start, end.clamp(0, 1), curve: Curves.easeOutCubic),
      ),
    );
  }

  Animation<double> _buildFadeAnimation(int index) {
    final start = index * 0.1;
    final end = start + 0.3;
    return Tween<double>(begin: 0, end: 1).animate(
      CurvedAnimation(
        parent: _controller,
        curve: Interval(start, end.clamp(0, 1), curve: Curves.easeOut),
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _controller,
      builder: (context, _) {
        return Column(
          children: List.generate(itemCount, (index) {
            final slide = _buildSlideAnimation(index);
            final fade = _buildFadeAnimation(index);

            return Transform.translate(
              offset: Offset(slide.value, 0),
              child: Opacity(
                opacity: fade.value,
                child: Card(
                  margin: const EdgeInsets.symmetric(
                    horizontal: 16, vertical: 8,
                  ),
                  child: ListTile(
                    leading: CircleAvatar(child: Text('${index + 1}')),
                    title: Text('Item ${index + 1}'),
                    subtitle: Text('从右侧滑入，依次错开'),
                  ),
                ),
              ),
            );
          }),
        );
      },
    );
  }
}
```

### TweenSequence：多阶段动画

```dart
// 一个动画分多个阶段，每段不同的缓动曲线
final animation = TweenSequence<double>([
  TweenSequenceItem(
    tween: Tween(begin: 0.0, end: 1.2)
        .chain(CurveTween(curve: Curves.easeOut)),
    weight: 40, // 占总时长的 40%
  ),
  TweenSequenceItem(
    tween: Tween(begin: 1.2, end: 0.9)
        .chain(CurveTween(curve: Curves.easeInOut)),
    weight: 30,
  ),
  TweenSequenceItem(
    tween: Tween(begin: 0.9, end: 1.0)
        .chain(CurveTween(curve: Curves.easeOut)),
    weight: 30,
  ),
]).animate(_controller);

// 效果：放大到 1.2 → 回弹到 0.9 → 稳定到 1.0（弹性效果）
```

## 🦸 2. Hero 动画高级用法

### 基础 Hero 的局限

```dart
// 基础用法：两个页面共享同一个 tag
Hero(tag: 'avatar', child: CircleAvatar(/*...*/))
```

基础 Hero 只能做简单的位置 + 大小过渡。如果你想在飞行过程中**改变 Widget 的形状**（比如从圆形头像变成方形封面），需要自定义。

### 自定义 flightShuttleBuilder

```dart
Hero(
  tag: 'card-${item.id}',
  // 自定义飞行过程中的 Widget
  flightShuttleBuilder: (
    BuildContext flightContext,
    Animation<double> animation,
    HeroFlightDirection flightDirection,
    BuildContext fromHeroContext,
    BuildContext toHeroContext,
  ) {
    // 在飞行过程中插值圆角
    return AnimatedBuilder(
      animation: animation,
      builder: (context, child) {
        final borderRadius = BorderRadiusGeometryTween(
          begin: BorderRadius.circular(12),  // 列表页的圆角
          end: BorderRadius.circular(0),     // 详情页无圆角
        ).evaluate(animation);

        return ClipRRect(
          borderRadius: borderRadius as BorderRadius,
          child: Material(
            elevation: lerpDouble(2, 0, animation.value) ?? 0,
            child: Image.network(
              item.coverImage,
              fit: BoxFit.cover,
            ),
          ),
        );
      },
    );
  },
  child: ClipRRect(
    borderRadius: BorderRadius.circular(12),
    child: Image.network(item.coverImage, fit: BoxFit.cover),
  ),
)
```

### Hero + PageRouteBuilder 组合

```dart
Navigator.push(context, PageRouteBuilder(
  transitionDuration: const Duration(milliseconds: 500),
  reverseTransitionDuration: const Duration(milliseconds: 400),
  pageBuilder: (_, animation, __) => DetailPage(item: item),
  transitionsBuilder: (_, animation, __, child) {
    // 页面整体淡入，Hero 单独做位置动画
    return FadeTransition(
      opacity: CurvedAnimation(
        parent: animation,
        curve: const Interval(0.3, 1.0),  // Hero 先飞，页面后淡入
      ),
      child: child,
    );
  },
));
```

## 🏀 3. 物理引擎动画

### 为什么需要物理动画？

普通动画用固定的缓动曲线（`Curves.easeOut`），看起来「机械」。物理动画模拟真实物理效果，看起来更**自然**。

| 对比 | 缓动曲线动画 | 物理动画 |
|------|------------|---------|
| 运动规律 | 预定义的数学曲线 | 模拟弹簧/摩擦/重力 |
| 终止条件 | 固定时长 | 速度趋近于 0 |
| 可中断性 | 截断跳转 | 从当前状态平滑过渡 |
| 真实感 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

### SpringSimulation 弹簧动画

```dart
class SpringCard extends StatefulWidget {
  const SpringCard({super.key});

  @override
  State<SpringCard> createState() => _SpringCardState();
}

class _SpringCardState extends State<SpringCard>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _animation;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(vsync: this);
    _setupSpring();
  }

  void _setupSpring() {
    // 弹簧参数
    const spring = SpringDescription(
      mass: 1.0,       // 质量：越大惯性越大
      stiffness: 300,  // 刚度：越大弹力越强
      damping: 15,     // 阻尼：越大越快停止
    );

    final simulation = SpringSimulation(spring, 0, 1, 0);
    // 参数：弹簧描述、起始位置、目标位置、初始速度

    _controller.animateWith(simulation);
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _controller,
      builder: (context, child) {
        return Transform.scale(
          scale: 0.5 + _controller.value * 0.5,  // 0.5 → 1.0
          child: child,
        );
      },
      child: GestureDetector(
        onTap: () {
          _controller.reset();
          _setupSpring();
        },
        child: Card(
          child: Padding(
            padding: const EdgeInsets.all(40),
            child: Text('点我弹一下', style: TextStyle(fontSize: 18)),
          ),
        ),
      ),
    );
  }
}
```

### 弹簧参数对比

| 参数 | 低值效果 | 高值效果 | 推荐值 |
|------|---------|---------|--------|
| **mass** (质量) | 轻盈快速 | 厚重缓慢 | 1.0 |
| **stiffness** (刚度) | 缓慢回弹 | 快速弹回 | 100-500 |
| **damping** (阻尼) | 弹很多次 | 快速停止 | 10-30 |

### FrictionSimulation 摩擦动画

```dart
// 模拟滑动后自然减速（像惯性滑动）
final simulation = FrictionSimulation(
  0.135,    // 拖拽系数
  0,        // 初始位置
  1000,     // 初始速度（像素/秒）
);

_controller.animateWith(simulation);
```

## 🎬 4. Rive 集成：复杂交互式动画

### 为什么用 Rive？

| 对比 | Flutter 原生动画 | Lottie | Rive |
|------|----------------|--------|------|
| 文件格式 | 代码 | .json | .riv |
| 制作方式 | 写代码 | After Effects | Rive Editor |
| 文件体积 | — | 较大 | 极小（通常 < 50KB） |
| 运行时性能 | 取决于实现 | 中等 | 极高（自有渲染引擎） |
| 交互能力 | 完全可控 | 仅播放 | 状态机（强交互） |
| 适合场景 | 简单过渡/变换 | 品牌动画/Splash | 按钮/角色/加载/引导 |

### 集成步骤

```yaml
# pubspec.yaml
dependencies:
  rive: ^0.13.0
```

### 基础播放


### 状态机控制（核心能力）

```dart
class InteractiveRive extends StatefulWidget {
  const InteractiveRive({super.key});

  @override
  State<InteractiveRive> createState() => _InteractiveRiveState();
}

class _InteractiveRiveState extends State<InteractiveRive> {
  StateMachineController? _stateMachineController;
  SMIBool? _isHovered;   // Rive 中定义的布尔输入
  SMITrigger? _onClick;  // Rive 中定义的触发器

  void _onRiveInit(Artboard artboard) {
    // 获取状态机
    _stateMachineController = StateMachineController.fromArtboard(
      artboard,
      'Button State Machine',  // Rive Editor 中定义的状态机名
    );

    if (_stateMachineController != null) {
      artboard.addController(_stateMachineController!);

      // 获取输入变量
      _isHovered = _stateMachineController!.findInput<bool>('isHovered')
          as SMIBool?;
      _onClick = _stateMachineController!.findInput<bool>('onClick')
          as SMITrigger?;
    }
  }

  @override
  Widget build(BuildContext context) {
    return MouseRegion(
      onEnter: (_) => _isHovered?.value = true,
      onExit: (_) => _isHovered?.value = false,
      child: GestureDetector(
        onTap: () => _onClick?.fire(),
        child: SizedBox(
          width: 200,
          height: 60,
          child: RiveAnimation.asset(
            'assets/animations/button.riv',
            onInit: _onRiveInit,
            fit: BoxFit.contain,
          ),
        ),
      ),
    );
  }

  @override
  void dispose() {
    _stateMachineController?.dispose();
    super.dispose();
  }
}
```

### Rive 状态机输入类型

| 类型 | Dart 类 | 用途 | 操作方式 |
|------|---------|------|---------|
| Boolean | `SMIBool` | 开关状态（hover/active） | `.value = true/false` |
| Number | `SMINumber` | 数值驱动（进度/分数） | `.value = 0.75` |
| Trigger | `SMITrigger` | 一次性事件（点击/完成） | `.fire()` |
