## 📊 你可能踩过的 Riverpod 坑

| 坑 | 现象 | 根因 |
|----|------|------|
| Provider 不刷新 | 数据变了 UI 不更新 | `ref.read` 和 `ref.watch` 用反了 |
| 循环依赖 | 编译报错 | Provider A watch B，B 又 watch A |
| 内存泄漏 | 页面关了 Provider 还在 | 没用 `autoDispose` |
| 状态丢失 | 页面返回时数据没了 | 用了 `autoDispose` 但不该用 |
| 测试困难 | 无法 mock Provider | 没用 Override 注入 |

## 🔍 1. Riverpod 核心原理

### 三层架构

```
ProviderScope（顶层容器）
    ↓ 持有
ProviderContainer（容器）
    ↓ 管理
ProviderElement（每个 Provider 的运行时实例）
    ↓ 持有
State（状态值）
```

### Provider 生命周期

```
创建 Provider（声明时）
    ↓
首次 read/watch（惰性初始化）
    ↓ 调用 build()
State 创建并缓存
    ↓
被其他 Provider watch → 建立依赖关系
    ↓
依赖变化 → 重新执行 build() → State 更新
    ↓
所有监听者取消监听 + autoDispose → dispose()
```

### ref.watch vs ref.read vs ref.listen

| 方法 | 用途 | 响应性 | 使用位置 |
|------|------|--------|---------|
| `ref.watch` | 监听状态变化 | ✅ 自动重建 | build 方法内 |
| `ref.read` | 一次性读取 | ❌ 不监听 | 回调/事件处理中 |
| `ref.listen` | 监听并执行副作用 | ✅ 不触发重建 | initState / build |
| `ref.invalidate` | 强制刷新 Provider | — | 需要手动刷新时 |

```dart
class MyWidget extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // ✅ watch：UI 依赖的数据，自动重建
    final count = ref.watch(counterProvider);

    // ✅ listen：执行副作用（Toast/导航），不触发重建
    ref.listen(errorProvider, (prev, next) {
      if (next != null) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text(next)),
        );
      }
    });

    return ElevatedButton(
      // ✅ read：事件处理中一次性读取
      onPressed: () => ref.read(counterProvider.notifier).increment(),
      child: Text('Count: $count'),
    );
  }
}
```

## 🧩 2. 高级 Provider 模式

### Family — 参数化 Provider

```dart
// 根据文章 ID 获取文章详情
@riverpod
Future<Article> articleDetail(Ref ref, String articleId) async {
  final api = ref.watch(apiServiceProvider);
  return api.getArticle(articleId);
}

// 使用：每个 articleId 独立缓存
final article = ref.watch(articleDetailProvider('abc123'));
```

### AutoDispose — 自动释放

```dart
// 页面关闭后自动释放（不再缓存状态）
@riverpod
Future<List<Comment>> comments(Ref ref, String postId) async {
  // ref.keepAlive() 可以临时阻止释放
  final link = ref.keepAlive();

  // 5 分钟后允许释放
  final timer = Timer(Duration(minutes: 5), () => link.close());
  ref.onDispose(() => timer.cancel());

  return await ref.read(apiProvider).getComments(postId);
}
```

### 什么时候用 autoDispose？

| 场景 | 用 autoDispose？ | 理由 |
|------|----------------|------|
| 用户认证状态 | ❌ | 全局状态，不能释放 |
| 主题/语言设置 | ❌ | 全局状态 |
| 文章详情页数据 | ✅ | 离开页面后可释放 |
| 搜索结果 | ✅ | 临时数据 |
| 购物车 | ❌ | 需要跨页面保持 |
| 表单输入 | ✅ | 提交后可释放 |

### AsyncNotifier 最佳实践

```dart
@riverpod
class ArticleListNotifier extends _$ArticleListNotifier {
  @override
  FutureOr<List<Article>> build() async {
    // 初始加载
    return _fetch();
  }

  Future<List<Article>> _fetch() async {
    final api = ref.read(apiServiceProvider);
    return api.getArticles();
  }

  // 下拉刷新
  Future<void> refresh() async {
    state = const AsyncLoading();
    state = await AsyncValue.guard(() => _fetch());
  }

  // 删除文章（乐观更新）
  Future<void> delete(String id) async {
    // 1. 先更新 UI（乐观更新）
    final previousState = state;
    state = AsyncData(
      state.valueOrNull?.where((a) => a.id != id).toList() ?? [],
    );

    try {
      // 2. 再调 API
      await ref.read(apiServiceProvider).deleteArticle(id);
    } catch (e) {
      // 3. 失败时回滚
      state = previousState;
      rethrow;
    }
  }
}
```

## 🏗️ 3. 状态持久化

### 与 SharedPreferences 结合

```dart
// Provider 级别的持久化
@riverpod
class ThemeController extends _$ThemeController {
  @override
  ThemeMode build() {
    // 从本地存储读取初始值
    final prefs = ref.watch(sharedPreferencesProvider);
    final isDark = prefs.getBool('isDarkMode') ?? false;
    return isDark ? ThemeMode.dark : ThemeMode.light;
  }

  void toggle() {
    final newMode = state == ThemeMode.dark ? ThemeMode.light : ThemeMode.dark;
    state = newMode;

    // 同步写入本地存储
    ref.read(sharedPreferencesProvider)
        .setBool('isDarkMode', newMode == ThemeMode.dark);
  }
}
```

### 与 Hive 结合（复杂数据）

```dart
@riverpod
class FavoriteController extends _$FavoriteController {
  late Box<Article> _box;

  @override
  List<Article> build() {
    _box = Hive.box<Article>('favorites');
    return _box.values.toList();
  }

  void toggle(Article article) {
    if (_box.containsKey(article.id)) {
      _box.delete(article.id);
    } else {
      _box.put(article.id, article);
    }
    state = _box.values.toList();
  }

  bool isFavorited(String id) => _box.containsKey(id);
}
```

## 🧪 4. 测试策略

### 单元测试 Provider

```dart
void main() {
  test('counterProvider increments correctly', () {
    // 1. 创建独立的容器
    final container = ProviderContainer();
    addTearDown(container.dispose);

    // 2. 读取初始值
    expect(container.read(counterProvider), 0);

    // 3. 执行操作
    container.read(counterProvider.notifier).increment();

    // 4. 验证结果
    expect(container.read(counterProvider), 1);
  });

  test('articleListProvider with mock API', () async {
    // Mock API
    final mockApi = MockApiService();
    when(mockApi.getArticles()).thenAnswer(
      (_) async => [Article(id: '1', title: 'Test')],
    );

    // Override Provider
    final container = ProviderContainer(
      overrides: [
        apiServiceProvider.overrideWithValue(mockApi),
      ],
    );

    // 等待 AsyncProvider 完成
    await container.read(articleListProvider.future);

    // 验证
    final articles = container.read(articleListProvider).valueOrNull;
    expect(articles, hasLength(1));
    expect(articles!.first.title, 'Test');
  });
}
```
