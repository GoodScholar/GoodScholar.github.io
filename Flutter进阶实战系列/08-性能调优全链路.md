## 📊 性能基准线

| 指标 | 优秀 | 合格 | 需要优化 |
|------|------|------|---------|
| 冷启动时间 | < 1s | < 2s | > 3s |

## 🔥 1. 启动优化

### 冷启动流程

```
用户点击图标
    ↓
系统创建进程（不可控）
    ↓
Flutter Engine 初始化（~300ms）
    ↓
Dart VM 启动 + main() 执行
    ↓
Widget 树构建 + 首帧渲染
    ↓
用户看到界面
```

### 优化策略

| 优化点 | 做法 | 节省时间 |
|--------|------|---------|
| 懒加载 | 非首屏的初始化放到 `WidgetsBinding.addPostFrameCallback` | 200-500ms |
| 减少首屏 Widget | 首屏只加载可见区域 | 100-300ms |
| 预编译 Shader | `flutter build --bundle-sksl-path` | 首次动画卡顿消除 |
| Splash 优化 | `flutter_native_splash` 实现无缝过渡 | 感知加速 |
| 异步初始化 | Firebase/Hive 等初始化并行执行 | 300-800ms |

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  // ✅ 并行初始化（而不是 await 串行）
  await Future.wait([
    Hive.initFlutter(),
    Firebase.initializeApp(),
    SharedPreferences.getInstance().then((p) => _prefs = p),
  ]);

  runApp(const MyApp());
}
```

### 延迟初始化

```dart
class MyApp extends StatefulWidget {
  @override
  State<MyApp> createState() => _MyAppState();
}

class _MyAppState extends State<MyApp> {
  @override
  void initState() {
    super.initState();
    // ✅ 首帧渲染后再执行非关键初始化
    WidgetsBinding.instance.addPostFrameCallback((_) {
      _initAnalytics();
      _checkForUpdates();
      _preloadImages();
    });
  }
}
```

## 🎬 2. 渲染优化

### DevTools Timeline 分析

```bash
# 用 Profile 模式运行（Release 性能 + Debug 工具）
flutter run --profile
```

### 常见渲染问题排查

| 问题 | 症状 | 诊断 | 解法 |
|------|------|------|------|
| 过度重建 | 帧率波动 | DevTools → Widget rebuild | 提取子 Widget + const |
| 过度绘制 | 页面卡顿 | Performance Overlay 分绿 | `RepaintBoundary` |
| 长列表卡 | 快速滚动白屏 | Timeline → Build 过长 | `itemExtent` + 缓存 |
| 动画卡 | 首次动画掉帧 | Timeline → Shader 编译 | Shader 预热 |

### 减少 Widget 重建

```dart
// ❌ 差：整个方法每次都重建
class BadExample extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        Text('标题'),
        ExpensiveWidget(), // 每次 build 都创建新实例
        Text('底部'),
      ],
    );
  }
}

// ✅ 好：用 const 标记不变的部分
class GoodExample extends StatelessWidget {
  const GoodExample({super.key});

  @override
  Widget build(BuildContext context) {
    return const Column(
      children: [
        Text('标题'),            // const → 不重建
        ExpensiveWidget(),       // const → 不重建
        Text('底部'),            // const → 不重建
      ],
    );
  }
}
```

### RepaintBoundary 隔离重绘

```dart
// ❌ 差：进度条动画导致整个页面重绘
Stack(
  children: [
    BackgroundWidget(),  // 每帧都被重绘
    AnimatedProgress(),  // 动画源
  ],
)

// ✅ 好：隔离动画区域
Stack(
  children: [
    const BackgroundWidget(),
    RepaintBoundary(        // 只在这个范围内重绘
      child: AnimatedProgress(),
    ),
  ],
)
```

## 🧠 3. 内存优化

### 图片缓存策略

```dart
// 全局设置图片缓存上限
void main() {
  PaintingBinding.instance.imageCache.maximumSize = 100;      // 最多缓存 100 张
  PaintingBinding.instance.imageCache.maximumSizeBytes = 50 << 20; // 50MB

  runApp(const MyApp());
}
```

### 大图加载

```dart
// ✅ 指定 cacheWidth/cacheHeight 减少内存
Image.network(
  'https://example.com/large-image.jpg',
  cacheWidth: 400,  // 解码后宽度限制为 400px
  // 原图 4000x3000 → 内存占用从 48MB 降到 0.48MB
)
```

### 内存泄漏排查

| 常见泄漏源 | 现象 | 解法 |
|-----------|------|------|
| `Timer.periodic` 未取消 | 页面关了还在跑 | `dispose()` 中取消 |
| `StreamSubscription` 未取消 | 持续监听已销毁的 Widget | `dispose()` 中取消 |
| `AnimationController` 未 dispose | 内存持续增长 | `dispose()` 中释放 |
| 全局 Notifier 持有页面引用 | 页面无法回收 | 使用弱引用 / autoDispose |

```dart
class _MyPageState extends State<MyPage> {
  late final AnimationController _controller;
  late final StreamSubscription _sub;
  Timer? _timer;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(vsync: this);
    _sub = someStream.listen((_) {});
    _timer = Timer.periodic(Duration(seconds: 1), (_) {});
  }

  @override
  void dispose() {
    _controller.dispose();  // ✅ 释放动画控制器
    _sub.cancel();          // ✅ 取消流订阅
    _timer?.cancel();       // ✅ 取消定时器
    super.dispose();
  }
}
```

## 📦 4. 包体积优化

### 分析包体积

```bash
# 生成体积分析报告
flutter build apk --analyze-size
flutter build ios --analyze-size
```

### 优化手段

| 优化 | 效果 | 做法 |
|------|------|------|
| **Tree Shaking** | 自动移除未使用代码 | Release 自动开启 |
| **代码混淆** | 缩短类名方法名 | `--obfuscate --split-debug-info` |
| **图片压缩** | 减少 asset 体积 | WebP 替换 PNG，tinypng 压缩 |
| **移除未用资源** | 减少 asset 大小 | 清理 assets/ 目录 |
| **拆分 ABI** | 按架构分包 | `--split-per-abi`（Android） |
| **字体裁剪** | 只包含用到的字符 | Google Fonts 按需加载 |

```bash
# Android 分 ABI 打包（每个 APK 小约 30%）
flutter build apk --split-per-abi

# 代码混淆 + 调试信息分离
flutter build apk --obfuscate --split-debug-info=debug-info/
```

### 生产阶段

```dart
// 自定义性能追踪
void trackPageLoad(String pageName) {
  final stopwatch = Stopwatch()..start();

  WidgetsBinding.instance.addPostFrameCallback((_) {
    stopwatch.stop();
    analytics.trackTiming(
      category: 'page_load',
      label: pageName,
      duration: stopwatch.elapsedMilliseconds,
    );
  });
}
```
