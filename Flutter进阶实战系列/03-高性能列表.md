## 🧩 1. Sliver 体系全解

### 什么是 Sliver？

Sliver 是 Flutter 滚动体系的基础「砖块」。`ListView`、`GridView` 本质上都是 `CustomScrollView` + 某种 Sliver 的语法糖。

```
CustomScrollView — 滚动容器
├── SliverAppBar         — 可折叠应用栏
├── SliverPersistentHeader — 粘性头部
├── SliverList             — 线性列表
├── SliverGrid             — 网格列表
├── SliverToBoxAdapter     — 放任意 Widget
├── SliverFillRemaining    — 填充剩余空间
└── SliverPadding          — 内边距包装
```

### 常用 Sliver 一览

| Sliver | 用途 | 子组件类型 |
|--------|------|----------|
| `SliverAppBar` | 折叠/展开的 AppBar | flexibleSpace |
| `SliverPersistentHeader` | 固定在顶部的粘性 Header | delegate |
| `SliverList` | 竖向列表 | delegate (builder) |
| `SliverGrid` | 网格 | delegate + gridDelegate |
| `SliverToBoxAdapter` | 放一个普通 Widget | child |
| `SliverFillRemaining` | 填充剩余空间 | child |
| `SliverPadding` | 给 Sliver 加内边距 | sliver |

### 实战：仿小红书首页布局

```dart
class XhsHomePage extends StatelessWidget {
  const XhsHomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return CustomScrollView(
      slivers: [
        // 1. 可折叠搜索栏
        SliverAppBar(
          floating: true,
          snap: true,
          title: _SearchBar(),
          expandedHeight: 100,
          flexibleSpace: FlexibleSpaceBar(
            background: _BannerCarousel(),
          ),
        ),

        // 2. 分类导航（粘性头部）
        SliverPersistentHeader(
          pinned: true,
          delegate: _CategoryHeaderDelegate(
            minHeight: 50,
            maxHeight: 50,
            child: _CategoryTabs(),
          ),
        ),

        // 3. 间距
        const SliverPadding(padding: EdgeInsets.only(top: 8)),

        // 4. 瀑布流内容
        SliverMasonryGrid.count(
          crossAxisCount: 2,
          mainAxisSpacing: 8,
          crossAxisSpacing: 8,
          childCount: 20,
          itemBuilder: (context, index) => _WaterfallCard(index: index),
        ),
      ],
    );
  }
}

// 粘性头部 Delegate
class _CategoryHeaderDelegate extends SliverPersistentHeaderDelegate {
  final double minHeight;
  final double maxHeight;
  final Widget child;

  _CategoryHeaderDelegate({
    required this.minHeight,
    required this.maxHeight,
    required this.child,
  });

  @override
  double get minExtent => minHeight;

  @override
  double get maxExtent => maxHeight;

  @override
  Widget build(BuildContext context, double shrinkOffset, bool overlapsContent) {
    return Container(
      color: Theme.of(context).scaffoldBackgroundColor,
      child: child,
    );
  }

  @override
  bool shouldRebuild(covariant _CategoryHeaderDelegate oldDelegate) {
    return oldDelegate.minHeight != minHeight ||
        oldDelegate.maxHeight != maxHeight ||
        oldDelegate.child != child;
  }
}
```

```dart
import 'package:flutter_staggered_grid_view/flutter_staggered_grid_view.dart';

class WaterfallGrid extends StatelessWidget {
  final List<CardItem> items;

  const WaterfallGrid({super.key, required this.items});

  @override
  Widget build(BuildContext context) {
    return MasonryGridView.count(
      crossAxisCount: 2,
      mainAxisSpacing: 8,
      crossAxisSpacing: 8,
      padding: const EdgeInsets.all(8),
      itemCount: items.length,
      itemBuilder: (context, index) {
        final item = items[index];
        return Card(
          clipBehavior: Clip.antiAlias,
          shape: RoundedRectangleBorder(
            borderRadius: BorderRadius.circular(12),
          ),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              // 图片（不同高度是瀑布流的关键）
              CachedNetworkImage(
                imageUrl: item.imageUrl,
                fit: BoxFit.cover,
                // 不指定固定高度，让图片按原始比例显示
              ),
              Padding(
                padding: const EdgeInsets.all(10),
                child: Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    Text(item.title,
                        style: const TextStyle(fontWeight: FontWeight.w600),
                        maxLines: 2,
                        overflow: TextOverflow.ellipsis),
                    const SizedBox(height: 6),
                    Row(
                      children: [
                        CircleAvatar(radius: 10,
                            backgroundImage: NetworkImage(item.avatar)),
                        const SizedBox(width: 6),
                        Text(item.author,
                            style: TextStyle(fontSize: 12, color: Colors.grey)),
                        const Spacer(),
                        Icon(Icons.favorite_border, size: 14, color: Colors.grey),
                        const SizedBox(width: 2),
                        Text('${item.likeCount}',
                            style: TextStyle(fontSize: 12, color: Colors.grey)),
                      ],
                    ),
                  ],
                ),
              ),
            ],
          ),
        );
      },
    );
  }
}
```

## 📜 3. 无限滚动分页

### ScrollController + 预加载

```dart
class InfiniteListPage extends ConsumerStatefulWidget {
  const InfiniteListPage({super.key});

  @override
  ConsumerState<InfiniteListPage> createState() => _InfiniteListPageState();
}

class _InfiniteListPageState extends ConsumerState<InfiniteListPage> {
  final ScrollController _scrollController = ScrollController();
  static const _preloadThreshold = 300.0; // 距底部 300px 时预加载

  @override
  void initState() {
    super.initState();
    _scrollController.addListener(_onScroll);
  }

  void _onScroll() {
    final maxScroll = _scrollController.position.maxScrollExtent;
    final currentScroll = _scrollController.offset;

    // 距底部不足 threshold 时触发加载
    if (maxScroll - currentScroll <= _preloadThreshold) {
      ref.read(articleListProvider.notifier).loadMore();
    }
  }

  @override
  Widget build(BuildContext context) {
    final state = ref.watch(articleListProvider);

    return RefreshIndicator(
      onRefresh: () => ref.read(articleListProvider.notifier).refresh(),
      child: ListView.builder(
        controller: _scrollController,
        itemCount: state.items.length + (state.hasMore ? 1 : 0),
        itemBuilder: (context, index) {
          // 最后一个 item 是加载指示器
          if (index == state.items.length) {
            return const Padding(
              padding: EdgeInsets.all(16),
              child: Center(child: CircularProgressIndicator()),
            );
          }
          return ArticleCard(article: state.items[index]);
        },
      ),
    );
  }

  @override
  void dispose() {
    _scrollController.dispose();
    super.dispose();
  }
}
```

### Riverpod 分页 Provider

```dart
@riverpod
class ArticleList extends _$ArticleList {
  int _page = 1;
  bool _isLoading = false;

  @override
  FutureOr<PaginatedState<Article>> build() async {
    return _fetchPage(1);
  }

  Future<PaginatedState<Article>> _fetchPage(int page) async {
    final articles = await ref.read(apiServiceProvider).getArticles(page: page);
    return PaginatedState(
      items: articles,
      hasMore: articles.length >= 20, // 每页 20 条
    );
  }

  Future<void> loadMore() async {
    if (_isLoading) return;
    final currentState = state.valueOrNull;
    if (currentState == null || !currentState.hasMore) return;

    _isLoading = true;
    _page++;

    try {
      final newPage = await _fetchPage(_page);
      state = AsyncData(PaginatedState(
        items: [...currentState.items, ...newPage.items],
        hasMore: newPage.hasMore,
      ));
    } catch (e) {
      _page--; // 失败回退页码
    } finally {
      _isLoading = false;
    }
  }

  Future<void> refresh() async {
    _page = 1;
    state = const AsyncLoading();
    state = AsyncData(await _fetchPage(1));
  }
}

class PaginatedState<T> {
  final List<T> items;
  final bool hasMore;

  const PaginatedState({required this.items, required this.hasMore});
}
```

## ⚡ 4. 列表性能优化

### 性能杀手排查表

| 问题 | 现象 | 解法 |
|------|------|------|
| 没用 `builder` | 一次性创建所有 item，内存爆炸 | 改用 `ListView.builder` |
| 缺少 `itemExtent` | 滚动时需要逐个测量高度 | 已知高度时指定 `itemExtent` |
| 图片不缓存 | 滚动时反复加载图片 | 用 `CachedNetworkImage` |
| rebuild 范围过大 | 一个 item 变化导致全部重建 | `const` 构造 + `RepaintBoundary` |
| Key 使用不当 | 列表更新时 item 乱跳 | 每个 item 加 `ValueKey(id)` |
| `cacheExtent` 太小 | 快速滚动时白屏 | 增大 `cacheExtent`（默认 250） |

### 核心优化代码

```dart
ListView.builder(
  // ✅ 已知 item 高度时指定，性能提升显著
  itemExtent: 120,

  // ✅ 增大缓存区域，减少快速滚动白屏
  cacheExtent: 500,

  // ✅ 每个 item 加唯一 Key
  itemBuilder: (context, index) {
    return RepaintBoundary(
      key: ValueKey(items[index].id),
      child: ArticleCard(article: items[index]),
    );
  },
)
```
