# 学习记录 0002: 代码级调试策略

**日期**: 2026-06-17
**关联任务**: 构建 React Flow 节点编排系统

## 核心洞见 (Key Insight)
在极高频重绘和事件触发（如鼠标拖拽导致 `onNodesChange` 频繁调用）的前端架构中，切忌使用简单的 `console.log` 进行调试。

## 关键实践
1. **条件断点**：在浏览器或 IDE 中，仅在满足特定条件（如特定 Node ID 或特定状态）时才挂起。
2. **防御性 `debugger`**：在自定义节点的关键渲染或数据处理前，使用 `debugger` 配合环境变量，在发生异常时硬拦截，查看调用栈。
3. **脱离 React 生命周期的状态探查**：利用 Zustand 的 `useStoreApi().getState()` 在控制台获取全量逻辑状态，避免影响渲染流。
