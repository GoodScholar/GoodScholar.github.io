# 学习记录 0003: DAG 拓扑执行机制

**日期**: 2026-06-17
**关联任务**: 构建 React Flow 节点编排系统

## 核心洞见 (Key Insight)
执行引擎的核心是一个处理 DAG 的 Event Loop。一个节点能否执行，取决于它所有的前置节点 (`getIncomers`) 是否都已经成功完成并产生了输出。

## 局限性与挑战
简单的 `while(queue.length > 0)` 循环是同步或单纯的 Promise 链式调用。在真实业务中（如 ComfyUI 的长时间渲染、或审批流的人工干预），这种持续运行的内存级队列会导致浏览器卡死，且如果页面刷新，整个执行进度会丢失。这就要求执行引擎必须具备随时“挂起 (Suspend)”的能力。
