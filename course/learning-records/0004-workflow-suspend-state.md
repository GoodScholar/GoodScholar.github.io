# 学习记录 0004: 工作流挂起与序列化快照

**日期**: 2026-06-17
**关联任务**: 构建 React Flow 节点编排系统

## 核心洞见 (Key Insight)
通过控制反转，节点执行逻辑可以向引擎返回一个特殊状态（如 `SUSPENDED`）。执行引擎捕获此状态后，使用 `break` 语句主动中断执行循环，从而实现了工作流断点。

## 快照的构成
在这个中断的瞬间，我们必须保存当前引擎的“快照”，才能在未来恢复执行：
1. `queue`: 剩余待执行的节点列表
2. `completedNodes`: 已经完成的节点及其计算结果
3. 实例 ID：用于关联数据库记录

得益于我们在架构上将 UI 视图层与逻辑状态层分离，我们此时只需保存极小量级的纯业务逻辑数据快照，而无需保存庞杂的 React Flow 坐标信息。
