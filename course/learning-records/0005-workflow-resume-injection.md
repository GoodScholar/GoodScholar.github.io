# 学习记录 0005: 恢复与上下文注入机制

**日期**: 2026-06-17
**关联任务**: 构建 React Flow 节点编排系统

## 核心洞见 (Key Insight)
工作流的“恢复 (Resume)”本质上是将外部系统的输入（例如用户的 UI 点击、Webhook 回调）转换为悬停节点的执行输出，并在完成对该节点的业务闭环后，再次将其下游节点推入执行队列，重新唤醒执行引擎（重新启动 `while` 循环）。

## 架构的对称美
在我们的架构设计中，**正常执行**与**挂起后恢复**共享了同一套下游派发逻辑：
- 正常执行：计算结果 -> `completedNodes.add()` -> 推入 `getOutgoers()` -> 继续循环。
- 挂起恢复：加载快照 -> 注入外部输入作为结果 -> `completedNodes.add()` -> 推入 `getOutgoers()` -> 重启循环。
