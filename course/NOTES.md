# 学习者偏好与笔记 (Notes)

## 学习者背景
- 熟练的 React/TS 开发者，熟悉状态管理。

## 教学策略
- 课程可以直接切入架构设计和核心逻辑，无需赘述 React 或 TS 基础语法。
- 重点关注**架构设计**和**工作流引擎原理**。

## 核心概念区分
学习者明确提出了两个需要重点掌握的概念，在后续教学中必须严格区分并深入讲解：
1. **调试断点 (Debugging Breakpoints)**：开发人员在编写节点编排系统时，如何利用浏览器的 DevTools 或 IDE 进行代码调试。
2. **工作流断点 (Workflow Breakpoints)**：节点执行引擎在运行业务逻辑时，遇到特定节点（如等待用户输入、等待异步长任务）时主动挂起 (Suspend) 工作流，保存上下文，并在后续恢复 (Resume) 执行的系统架构设计。
