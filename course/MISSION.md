# 学习任务 (Mission)

## 目标
从零开始打造一个类似于 tapNow 或是 libtv + comfyui 的 React 节点编排系统，并在实现过程中掌握以下理论与实践技能：
1. **React Flow 节点编排基础与进阶**：从零构建节点编排器界面。
2. **调试断点 (Debugging Breakpoints)**：掌握在节点编排系统内部代码的调试与问题定位。
3. **工作流断点 (Workflow Breakpoints)**：从架构层面实现节点执行过程中的暂停与恢复机制（Stateful Execution）。

## 学习者背景
- **经验水平**：熟练 (Proficient)
- **核心技术栈**：React, TypeScript, 状态管理 (Zustand/Redux 等)

## 预期成果
- 能够独立设计和实现一个支持复杂工作流暂停、恢复的节点编排引擎。
- 掌握在前端执行工作流时的状态持久化和打断点逻辑。
